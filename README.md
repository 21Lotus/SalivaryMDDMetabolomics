## Executive Summary
This code walks through the process of pre-processing mass spectrometry files, analyzing them using baseline models and unsupervised learning, training a transformer model, identifying the key molecules up and down regulated in depression, and validates the biomarkers on a separate proteomics dataset. All code maintained in this file was developed using Google Colab, ran on their free GPUs, and was used for the educational purpose of developing this research project.

---

## Workflow
This project is implemented as a modular, sequential computational pipeline. Each notebook performs a distinct task and necessary function. There is no single “main” file, as later code files depend on the output of earlier ones. The main code consists of the core analytical and modeling notebooks: 03_MetaboliteAnalysis, 04_transformer, 05_transformer_cpu, 06_analysis.

**Execution Order:**  
`01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 09 → 10`
